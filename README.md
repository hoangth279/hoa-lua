# Họa Lụa

Website for the Họa Lụa digital marketing campaign.

## Tech Stack

### Frontend
- React
- Vite
- React Router
- Axios

### Backend
- Node.js
- Express.js
- MySQL

## Development

Install dependencies:

npm install

Run frontend and backend:

npm run dev

Frontend:
http://localhost:5173

Backend:
http://localhost:3000

API health check:
http://localhost:3000/api/health
